# 灯潮纪 / Lanternwake — 两盏航灯

一款可从头到尾完成两章主线与三岸旅程的原创怪兽收集 RPG。使用 **Godot 4.7.2**，美术、像素动画、界面、网格、音乐和音效均由源代码在运行时生成。默认简体中文，可随时切换英文。英文为代码点阵字，中文由代码调用操作系统已有的中文字体绘制；项目不捆绑字体文件。无需插件、导入美术或在编辑器手动配置节点。

源码仓库：<https://github.com/beekim123/pocket-astra>。持续扩展计划见 `docs/design/expansion-roadmap.md`，当前实际完成和推送状态见 `docs/v2/status.md`。

## 直接运行

在 Godot 4.7.2 中导入根目录的 `project.godot`，按 **F5（运行项目）**。项目主场景已配置。

本机根目录已经有用户提供的 `Godot.app`，也可在此目录运行：

```sh
./Godot.app/Contents/MacOS/Godot --path .
```

解压 ZIP 后，用自己的 Godot 4.7.2 打开其中的 `project.godot` 即可。ZIP 不含引擎本体、缓存或任何二进制素材。

## 第一章：第一盏灯

群岛的航道被大雾吞没。岛民称为「鸣兽」的小生灵，仍然记得灯塔过去的旋律。你在醒潮港 Wakeharbor 结识守灯人 Edda，从三位伙伴中选择一位，前往烛苇原 Candle Reed Meadow，最后和道馆守灯人 Soren 一起唤醒回声。

这是一个完整、紧凑的第一章；通关后可继续浅鸣潮池支线，再乘船前往雨阶岛完成第二章。第一章 15–25 分钟为设计时长目标，尚未进行真实玩家计时。

1. 标题选择 **Begin a New Journey**，阅读 Edda 的介绍，选择初始伙伴。
2. 沿石路向右走，穿过木桥。离开石路，进入东岸苇草区触发遭遇。
3. 用 **Strike** 把野生鸣兽削弱，再 **Capture**。第一次捕捉在半血以下必定成功；之后在四分之一血以下必定成功。
4. 回到桥东侧，靠近红衣训练家 **Ivo**，按 E 挑战两只鸣兽。
5. 沿东岸竖直石路向北，靠近灯塔前的 **Soren**，按 E 挑战第一座道馆。
6. 获胜后得到 **First Light Crest**，观看本章结局。可返回岛上收集原有八种鸣兽，也可乘船前往雨阶岛寻找三位新伙伴。

村里白衣的 **Mira** 免费回复全队，并把回声容器补到至少 12 个、药剂补到至少 5 瓶。训练家和道馆挑战开始前也会回复全队。失败会回村恢复，不丢伙伴和主线进度。

## 海岸支线：浅鸣潮池（1.2）

选择初始伙伴后，从醒潮港向南走，在岸边找到修灯匠 **塔薇 / Tavi**。她请你帮助追逐倒影而搁浅的愿灯蛾。沿南侧石堤进入浅鸣潮池，绕过水池，沿东侧干燥岩岸走到小小的灯栏旁按 E 救援，再回港向塔薇报平安。

- 救援不要求捕捉或战斗，不消耗道具，六只满队也能完成。回港可领取一次性的 **4 个回声瓶和 2 瓶药剂**。
- 风孔石、流水槽、铜片风铃是三个独立观察点，可按任意顺序聆听，也可以先观察、后救援。全部记录后奏出原创的海岸应答短句，静音时仍有亮光和文字反馈。
- 潮池西侧海草中可遇见帆溪獭、卵石甲、愿灯蛾，等级 2–4；第一次捕捉仍沿用愿灯蛾 Lv3 的教学规则。安全石路和交互点不会触发潮池遭遇。
- 行囊的地图页可切换「岛屿地图 / 潮池地图」，显示救援点、三个观察点、玩家位置和返港方向。
- 旧版存档可直接继续，新增支线默认未完成。支线不增加第一道馆的前置条件，不影响原有通关路线。

## 雨阶通航与水路修复（1.3 / 第 03A 轮）

点亮第一盏灯后，在醒潮港西侧石路尽头找到渡船人 **维恩 / Venn**。按 E 交谈，再选择「登船」前往雨阶岛；「留在这里」或 Esc 可取消。雨阶码头的维恩随时提供免费返航，岛上不用道具也能回家。

**奥菈 / Orla** 在雨阶码头西侧提供免费休息和补给。沿中央石路与木桥寻找「屋檐引水口、桥边接水槽、菜圃出水口」，任意顺序交互修复三处水路，随后向奥菈报告。每段水渠会从静止暗水变为流动蓝水，并点亮标记；完工补给只领取一次。

- 存档记录当前岛屿和水路进度，旧档自动视为仍在醒潮港。雨阶战败在当地码头回复，不会把角色放回错误岛屿。
- 地图页增加雨阶地图，标出渡船、奥菈和三处水路。当地花草可遇见雨阶三位新伙伴，以及帆溪獭、苔铃鹿、苇锋鹭、霆风鳐与夜辉鸮，等级 5–7。
- 双向渡船、新村落和完整修复支线已完成；三位地区新伙伴在 1.4 / 第 03B 轮加入。第二道馆在 1.5 / 第 04 轮加入。

## 雨阶伙伴与图鉴分页（1.4 / 第 03B 轮）

乘船抵达雨阶岛后，走入浅色植物区便有机会遇见 **檐溪蜥、阶纹蜗、灯纱蝠**，无需先完成修水路。三者各有原创代码像素造型、三帧正背面动画、专属招式与不同成长倾向。捕捉、升级、换兽、药剂等沿用原有战斗规则。

图鉴现有 **11 种、2 页**，每页八格。点击上一页/下一页，或按 **PageUp / PageDown** 翻页；末页只显示三个实际条目。图鉴显示动态总数、栖息地和集齐状态，未知雨阶条目也提供寻找方向。旧存档和原八种物种 ID 保持兼容，原八种所有48帧图像已逐字节验证不变。

## 第二章：第二盏航灯（1.5 / 第 04 轮）

修复雨阶岛三处水路并向奥菈交付后，沿中央石路向北，在北侧横路东端找到 **奈里 / Neri**。她的准备挑战使用檐溪蜥 Lv7 与阶纹蜗 Lv7；通过后继续沿中央路向北，到集雨航灯下挑战守灯人 **伊莱亚 / Ilya**。

- 第二道馆队伍：阶纹蜗 Lv8、檐溪蜥 Lv8、灯纱蝠 Lv9。两场挑战前免费回复全队，失败在雨阶码头恢复，原有进度和伙伴保留。
- 建议至少带三位伙伴，初始伙伴训练到 Lv7 左右，并利用雨阶地区伙伴补足属性。属性被抵抗时可用普通攻击，低血量及时用药；奥菈始终提供免费休息和补给。
- 奈里首次胜利给予4个回声瓶与2瓶药剂；道馆首次胜利给予6个回声瓶与3瓶药剂（道具上限999）。回看故事或重复交谈不会重复领奖。
- 获胜点亮六角集雨航灯，获得第二航灯徽记，观看独立第二章结局。之后可自由往返两岛；与伊莱亚交谈可回看第二结局。
- 地图和目标栏会随「修水路 → 奈里 → 伊莱亚 → 两灯亮起」更新。两个道馆分别保存完成状态；旧版存档的第二道馆默认未完成。

## 风图埠短航（1.6 / 第 05 轮）

点亮第二航灯后，到雨阶码头东侧找 **玛伦 / Maren**，免费乘船前往 **风图埠 / Windchart Quay**。这是以观察和判断为主的小旅程，没有强制战斗或物资消耗；主港玛伦也提供免费回复补给。

1. 任意顺序观察西北的风标、东侧潮尺和东北的对灯，三条线索会保存到地图笔记。
2. 回到中央航图台：东侧礁道迎风，北侧浅滩水浅，南侧水道通往背风弯。选择安全航线抵达独立小泊位。选错会解释原因，留在原处立即重试，不扣道具；Esc可取消。
3. 在 **背风泊位 / Lee Berth** 与制帆人 **赛菈 / Sela** 交谈，点亮靠泊灯，首次获得4个回声瓶、2瓶药剂（总数上限999）。重复拜访不重复发奖。
4. 南侧小艇免费回风图主港；码头渡船免费回雨阶，再搭原渡船回醒潮港。途中与结尾进度均能保存；静音与六只满队也不会卡住任务。

新增地图标明航标、航图台、回复处、渡船和泊位；已读线索可随时回看。风图埠及泊位由代码生成海面、石堤、木船棚、帆布工具与航灯。现有11种鸣兽、两个道馆和全部旧存档继续兼容。

## 操作

| 输入 | 功能 |
|---|---|
| WASD / 方向键 | 移动；在菜单中切换选项 |
| Shift | 奔跑 |
| E / Enter / Space | 对话、确认、加快战斗文字 |
| 鼠标左键 | 点击所有界面按钮 |
| Tab / Esc | 打开或关闭行囊 |
| P / J | 队伍 / 图鉴 |
| PageUp / PageDown | 图鉴上一页 / 下一页 |
| F5 | 探索时快速保存（在游戏窗口中） |
| M | 静音或恢复声音 |
| L | 随时切换简体中文 / English |
| F11 | 全屏或窗口模式 |
| 1–3 | 选伙伴时直接选择 |
| 1–7 | 战斗：普攻、专属技、捕捉、药剂、防御、换兽、逃离 |

防御会回复少量 HP 并削减本回合所受伤害。药剂先回复，随后敌方行动。换兽消耗一回合；倒下时自动派出健康伙伴。普通攻击不受属性抵抗影响，适合温和削血和不利属性对局。战斗面板会显示当前专属技的属性倍率。

基础克制环：**烬 → 森 → 潮 → 烬**。辉克暮；岩克烬和霆；霆克潮和辉；暮克森。等级上限 12，战斗胜利给予经验及补给，后备伙伴也获得部分经验。

## 存档

单一存档，选择伙伴、完成遭遇、领取宝箱、调整队伍后保存；探索每 35 秒自动保存。可按 F5 或进入设置手动保存。保存使用临时文件再原子替换，损坏或版本不兼容的存档不会破坏内存状态。

macOS 默认路径：

```text
~/Library/Application Support/Lanternwake/lanternwake.json
```

语言偏好独立保存在同目录的 `preferences.cfg`，不会修改伙伴、图鉴或通关存档。可在标题右下角或行囊的设置页切换语言，重启后保留选择。中文优先使用系统的冬青黑体简体中文、黑体、微软雅黑、思源/Noto Sans CJK 或文泉驿，苹方为后备；本机已逐字检查完整中文目录。没有中文系统字体的精简系统需要先安装 CJK 字体，或按 L 切换回英文。仓库不复制或嵌入系统字体。

关闭未完成的战斗时保留上一次安全存档；战斗不支持中途恢复。标题的 New Journey 会先给出覆盖提示，在选择新伙伴时写入新的存档。

## 技术与美术决定

- **像素精灵 + 真实 3D 微缩场景**：正交摄影机、厚实地形断面、瓦屋、石路和木桥。人物、鸣兽与层叠树叶采用透明点阵纹理；角色和环境投下真实阴影。
- **兼容性渲染**：OpenGL Compatibility 路径，轻量屏幕倾斜软焦与高光柔化。无需 Forward+、外部后处理插件或烘焙光照。远近景柔化是可关闭的屏幕空间摄影效果，不声称是物理镜头景深。
- **原创配乐**：「A Light to Return To」八小节动机加第二段应答，构成十六小节编排。探索采用 D 大调，战斗和道馆在 D 小调重新配器。长笛感音色、拨弦、低音与轻打击均实时合成。
- **稳定运行**：缓存生成纹理、固定 60 FPS、Godot worker 池限制为 1；音频为 22,050 Hz，单次最多生成 2,048 帧，声音数量有上限。所有逻辑都在主线程；没有后台生成进程。
- **双语界面**：英文保留原创点阵字形；中文使用系统已有 CJK 字体，由代码完成布局与绘制。显示、测量和换行共用同一翻译入口，内部属性和存档 ID 不翻译。
