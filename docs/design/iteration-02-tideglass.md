# 第 02 轮：浅鸣潮池救援

2026-10-23，定时续作。实施依据：用户已授权自主连续扩展，每轮验证通过后提交推送。当前基线 `52efe21`，工作区干净。

## 本轮可玩内容与完成条件

在醒潮港南端增加石堤和潮池半岛。修灯匠塔薇请旅人帮助搁浅的愿灯蛾；玩家能绕过浅池走到目标，交互救回，再返港领取一次性补给。任务不要求战斗或捕捉，六只满队、零道具也能完成，原主线没有新前置。

三个原创声学小景：风孔石、流水槽、铜片风铃。任意顺序都可记录，观察全部后奏出短小的海岸应答旋律；每处有文字和亮光反馈，静音也能理解。不发重复奖励，不把被救目标强制加入队伍。

地图范围：石堤 x[-8.3,-5.6]、z[10,13.4]；半岛 x[-13.4,-2.6]、z[13,23.6]。浅水区域为不可行走的局部水池，其余湿岩为清楚的安全步行区。局部海草提供帆溪獭、卵石甲、愿灯蛾的低等级遭遇，靠近交互目标不遇敌。

## 模块与接口

- `tide_quest.gd`：纯规则，`interact(state, role)` 返回 speaker/lines/changed/sound，`objective` 返回支线提示，`marker_count` 和 `complete` 表示观察记录。只更改独立布尔标记和一次补给奖励。
- `game_state.gd`：在版本 1 中兼容添加可选布尔标记，严格校验类型、前置关系；旧档默认全部未完成。
- `encounter_tables.gd`：用稳定区域 ID 与注入随机数生成器选择遭遇；保留首次捕捉教学和原苇草表。
- `world.gd` / `tidepool_world.gd`：程序化海岸小景、边界、摄影机、交互和事件触发的进度视觉同步。区域 API 为 `area_id`、`encounter_region`、`sync_tide_progress`。
- `main.gd`：支线事件接入、保存、音效、遇敌；不修改原战斗规则。
- `game_ui.gd`：独立支线提示、潮池地图页；主线任务仍显示。
- `localization.gd` / `music.gd`：新增完整中英文本和四种短合成音。
