## 已实现

原创「第一盏灯」旅程：标题 → Edda 开场 → 三选一伙伴 → 烛苇原野生遭遇与捕捉 → Ivo 双兽训练家战 → Soren 双兽道馆战 → First Light Crest 结局 → 自由探索与八种图鉴收集。

包括六位队伍、升级、属性倍率、普通/专属攻击、防御回复、药剂、换兽、捕捉、逃离、失败恢复、免费补给、地图、图鉴、释放二次确认、自动/手动原子存档、坏档校验、静音、软焦开关及全屏。

美术为代码绘制的透明像素纹理、点阵字体、3D 网格与 Shader；音乐是原创固定旋律、和声与配器的实时合成。交付源码没有外部图片、音频、字体、模型文件。根目录原有 `Godot.app` 是用户提供的开发工具，不纳入资源和 ZIP。
