## 已实现

原创「第一盏灯」旅程：标题 → Edda 开场 → 三选一伙伴 → 烛苇原野生遭遇与捕捉 → Ivo 双兽训练家战 → Soren 双兽道馆战 → First Light Crest 结局 → 自由探索与八种图鉴收集。
